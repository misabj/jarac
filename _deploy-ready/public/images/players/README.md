# Slike igrača

Stavi PNG/JPG fajlove u ovaj folder, npr.:

```
public/images/players/nikolic-milos.jpg
public/images/players/savic-nemanja.jpg
```

Zatim u admin panelu pri izmeni igrača upiši u polje **Foto URL**:

```
/images/players/nikolic-milos.jpg
```

Preporučena dimenzija: 512x512 kvadrat, JPG ili WEBP, do ~200 KB.
